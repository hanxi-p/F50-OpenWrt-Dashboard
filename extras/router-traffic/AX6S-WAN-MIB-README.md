# AX6S 物理 WAN 计数修复 0.3.4

在0.3.3基础上修复 AX6S 硬件卸载导致 WAN 软件接口漏记：只读 Linux ethtool 获取物理 WAN 端口 RxBytes/TxBytes，不相加无线或 LAN 计数。只对 xiaomi,redmi-router-ax6s 放行，安装预检验证目标物理端口计数真实可读；不支持 CR6609、AX6S2 等其他设备，不修改卸载设置。

首次使用物理 MIB 时计数代次变化，新建基线并保留已有累计；原来漏记的历史不可精确重建。计数不可读时显示过期，不回退到不兼容的软件计数。原样式与其他功能按0.3.3保留。

本机小工具源码 native/read-port-stats.c，静态 ARM64 程序 bin/read-port-stats；构建支持从源码编译两个程序，或同时验证两者源码和二进制摘要后复用已有包。备份和回退仍使用安装器输出的备份目录。
