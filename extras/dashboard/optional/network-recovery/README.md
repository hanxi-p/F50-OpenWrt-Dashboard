# 故障触发的区域线路恢复

本目录是可选组件，不属于基础安装器，不会自动安装或启用。启用前须确认核心兼容性、区域池与控制器权限，备份当前配置；配置检查和隔离策略检查通过后，再热加载并读回活动组与辅助服务状态。脚本存在不等于启用完成。

私有/etc/mu300/network-recovery.json指定main_group、fallback_group、preferred_proxy、probe_interval、passive_interval。Ruby钩子只改既有组健康参数/优先级，成员及地区限制不扩展。检测间隔用于探测，不是换线计时器；fallback连接失败达到阈值可触发强制检查。粘性辅助进程只轮询本机控制器、钉住已选中的可用线路，健康时不切换、手动选择其他组时让开。凭据只在root私有/run目录，退出清理；不关闭Wi-Fi或重启蜂窝。

`ucode test-policy.uc`三轮检查健康保持、实际替代线路钉选、原节点恢复不抢回、手动选择优先和全坏不轮换。故障注入与重启/订阅后的状态连续性需要单独验收，不以隔离策略测试代替实际场景。应用前重新备份、核对运行核心API fixed/Set兼容与区域池，按用户明确范围执行。

可选设置 `notify_route: true` 时，向root私有RAM快照输出主策略解析到的实际叶节点；需要配合新版通知生产者。默认不启用。节点变化仅通过 Bark 通知，接收后十分钟过期；WxPusher 仅保留短信/故障，首次和新启动只建基线，持久序号去重；不新增公网探测或发送WAN/DNS故障。
