# 路由器本地样本采集

采样直接运行在ODI路由器服务内，电脑不参与持续采集；电脑后续承担脱敏、标注整理、训练和评估。当前已在F50试运行，其余节点需分别部署、验证能力后加入。

## 何时留样

每轮ODI观测后检查一次：同一MAC进入新的五分钟窗口、可用特征变化或启动批次变化时留样；相同窗口、相同特征不重复写入。启动时从日志恢复去重状态，时钟回退明确标记。窗口样本不是独立物理设备或独立连接样本，训练时必须按设备、连接批次及时间分组。

格式odi-sample-v2（恢复兼容v1）。包含唯一frame_id、router_id、boot_id、时间窗口、MAC、采样原因、缺失/来源质量、能力标记和标准化特征。site_id暂为空，未配置身份域前不据此跨节点合并。特征包括可用无线能力、DHCP、名称和已验证地址关联的mDNS；无可用特征也保留缺失标记，不伪造指纹。另保存白名单原始字段快照（每项最多2KiB、最多8项），保留单独出现的Vendor Class、请求选项和User Class，避免过早丢弃未来训练有用的信息。没有抓取通信正文或浏览历史。

## 文件与资源

- /etc/odi/dataset/samples-current.jsonl：当前原始样本。
- /etc/odi/dataset/samples-previous.jsonl：轮换上一份样本。
- /etc/odi/dataset/labels.jsonl：单独核实标签，采集器仅在不存在时建立空文件，永不自动写入标签或覆盖人工内容。
- /tmp/odi/dataset-status.json：采样运行状态、写入数量和预算提示。

目录0700、文件0600。每份采样日志最多4MiB，两份合计约8MiB；超限轮换会淘汰较早日志，需要长期训练资料时先导出归档。单条最大16KiB，每轮最多8条，每五分钟最多32条。大网络会受采样预算限制，不承诺每个设备每窗口都有记录。文件短写/损坏尾行保留供恢复，错误不会阻止原统计和网络转发。

标签为空意味着尚未建立训练真值；不同MAC、不同UUID或同时在线均不能直接自动生成正负标签。标签建议单独记录left_frame_id、right_frame_id、relation（same_device/different_device）、核实方法与时间。人工确认标签和系统候选必须分开；后续标注UI及管理API尚未完成。

## 多路由器汇总

各节点本地留样，保留各自router_id和采集能力。不要通过复制节点的/etc/odi状态来初始化新路由器，避免router_id重复。汇总到电脑后先脱敏MAC、名称、Client ID等标识，再生成匹配特征。现场确认的同一设备可跨节点建立正样本，同型号不同设备提供难负样本；不能凭同型号或同名自动标注。

训练/测试按实际设备和时间分组，连续轮询、同一窗口和漫游重复观测不能分散到两个集合制造虚高结果。当前没有经过真实标签训练的分类器。

## 验证范围

三轮共57项采样断言覆盖窗口去重、重启恢复、特征变化、启动批次、保留人工标签、预算、损坏尾行与4MiB轮换；三轮隔离完整采集通过。F50只重载ODI，不重启DHCP/Wi-Fi或原流量采集。断电耐久、跨节点汇总、标注界面、长时间写盘和真实分类准确率未验收。

样本含网络标识，保存在路由器本地，不自动上传云端或GitHub。公共仓库只保存采样代码和合成测试；原始样本及人工标签不应提交Git。
