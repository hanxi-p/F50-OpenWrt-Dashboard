# 后台会话时长

[返回功能目录](../../README.md#功能目录) · 功能ID：`session-timeout` · 诊断管理

## 功能

按需要延长后台登录保持时间，例如12小时。

使用者选择LuCI会话空闲期限，适用于输入密码后保持登录的设备；指定设备免密属于另一项功能。基础包只在配置缺失时使用2小时默认值，更新时保留已有期限；可按需要设置12小时或24小时。

12小时是可选设置示例，不是所有设备的固定值。修改时核对实际LuCI会话配置，确认新会话使用所选期限，同时保留退出登录。

## 需要使用者提供的选项

需要的空闲保持时长、是否与指定设备免密一起配置。

## 配置方法

保存现有LuCI配置，按所选期限更新会话设置，用新的登录会话读回验证。

```text
我选择 F50-OpenWrt-Dashboard 的 session-timeout 功能。
先读取此功能页与风险清单，核对我的系统、现有配置和选项；为我的设备准备配置，保留备份。
公开资料只用通用说明与示例；设备名单、凭据、密钥和实际配置保存到我的本机或设备私有文件。
配置后按功能页检查，交付结果和恢复方法。
```

## 验收

配置读回、新登录会话期限、普通密码登录、退出与重新登录；实际等待期限测试单独记录，不把配置值等同于已经等满12小时。

分别记录语法/配置、逻辑和多轮场景；通过、失败和未测留在使用者的执行记录中。恢复使用本次配置前保存的原件与状态。
