# SMTP邮箱参数

[返回功能目录](../../README.md#功能目录) · 功能ID：`smtp` · 其他功能

## 功能

单独配置发件邮箱、SMTP服务器、端口、TLS方式、收件人与授权码，并测试邮件发送链路。可供短信邮件转发使用；配置SMTP与启用短信转发分别选择。

## 使用者提供的选项

- 发件邮箱、SMTP地址、端口和TLS方式。
- 收件邮箱与自己的客户端授权码。
- 是否发送hello测试邮件。

授权码存入使用者设备的私有文件，不写入公开示例、命令参数或日志。465隐式TLS与587/STARTTLS按邮箱服务要求选择，保持证书校验。

## 配置与验收

先核对时间、DNS和SMTP软件，保存原配置，再按所选参数配置。检查权限、TLS、认证与邮件编码，核对SMTP返回和收件端实际收到；测试授权码错误、网络失败与恢复时使用隔离场景。

```text
我选择 F50-OpenWrt-Dashboard 的 smtp 功能。
使用我提供的邮箱参数配置SMTP，授权码只写私有文件；保留原配置和恢复方法。
按我选择发送hello测试，并区分SMTP接受与收件端收到。
未选择短信转发时，不自动启用短信发送服务。
```

参数格式与配套文件见[邮件配置说明](../sms-email.md)。恢复使用本次保存的邮箱配置和原服务状态。
