# 性能/能效模式

[返回功能目录](../../README.md#功能目录) · 功能ID：`power-mode` · 快捷控制

## 这项功能做什么

按需开关大核：性能全核，能效使用4个小核。

性能红、能效绿；切换显示“大核开启中/大核关闭中”；限时与错误反馈，不启用自动省电或休眠。

## 可以设置/需要准备什么

手动选模式；保持热点可管理，不承诺固定测速上限。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 power-mode 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

三轮往返、online/频率、AP/后台访问、超时恢复，最后恢复初始模式。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
