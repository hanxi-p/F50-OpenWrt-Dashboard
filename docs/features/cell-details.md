# 基站、小区与SIM详情

[返回功能目录](../../README.md#功能目录) · 功能ID：`cell-details` · 界面与设备

## 这项功能做什么

需要时展开查看基站、小区、地址与手机号。

将PCI、频点、注册和SIM详情移出首屏；手机号仅在SIM提供时显示；号码等隐私字段按页面保护方式展示。

## 可以设置/需要准备什么

选择需要核对的蜂窝字段，分享截图前遮住个人标识。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 cell-details 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

核对字段与实际SIM/注册状态；缺少手机号不编造。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
