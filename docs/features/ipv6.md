# IPv6多前缀学习

[返回功能目录](../../README.md#功能目录) · 功能ID：`ipv6` · 其他功能

## 这项功能做什么

学习蜂窝前缀并撤回失效前缀。

系统组件独立包，版本检查后部署；运营商未下发IPv6时单列不适用，不凭WAN有地址判定客户端可用。

## 可以设置/需要准备什么

匹配基础系统与NDP服务；代理开关对IPv6的影响另行验证。

## 如何选择与部署

使用[系统组件包](../../extras/system-reliability/README.md)，先运行兼容检查。该包内组件一同部署；本条用于选择检查/配置目标，不代表存在单文件通用安装器。

```text
我选择 F50-OpenWrt-Dashboard 的 ipv6 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

前缀加入/撤回与过期，LAN/WAN路由和客户端IPv6访问，代理开/关分别测。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
