# 本小时使用流量

[返回功能目录](../../README.md#功能目录) · 功能ID：`hourly-usage` · 流量套餐

## 这项功能做什么

显示北京时间当前小时接收+发送合计。

按小时记录求和，重复同周期记录合并；源统计按周期落盘，分钟旁证另选分钟流量日志。

## 可以设置/需要准备什么

按北京时间整点划分；不把最近60分钟滚动量混为当前自然小时。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 hourly-usage 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

小时边界、重复记录、反序及查询失败；失败不能显示成0。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
