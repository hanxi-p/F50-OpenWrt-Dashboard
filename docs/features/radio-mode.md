# 4G/自动5G切换

[返回功能目录](../../README.md#功能目录) · 功能ID：`radio-mode` · 快捷控制

## 这项功能做什么

点击立即切换，倒计时只提示预计等待。

显示目标模式与30秒倒计时；网络就绪提前结束；失败/失联不永久停在切换中，迟到响应不覆盖新状态。

## 可以设置/需要准备什么

选择4G或自动5G；使用实际SIM与信号条件，不猜测注册成功。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 radio-mode 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

三轮往返、刷新/超时/无响应/提前完成；登记实际注册与联网耗时。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
