# 自动/手动Wi-Fi信道

[返回功能目录](../../README.md#功能目录) · 功能ID：`channel` · 快捷控制

## 这项功能做什么

按当前地区与驱动能力选择合法非DFS信道。

自动是选中状态，手动白色；过滤DFS/no-IR及不完整80MHz组；不把地区码固定猜成CN。

## 可以设置/需要准备什么

保留现有国家码；手动信道从当前有效列表选择。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 channel 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

不同地区列表、非法/DFS拒绝、自动/手动状态、AP与手机重连。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
