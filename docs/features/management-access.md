# 会话时长、SSH与指定设备免密

[返回功能目录](../../README.md#功能目录) · 功能ID：`management-access` · 定向配置

## 这项功能做什么

按自己的设备配置后台访问方式。

通用面板安装默认2小时会话；当前维护设备另配12小时及指定MAC免密；SSH公钥由使用者自己生成，免密名单不公开。

## 可以设置/需要准备什么

MAC免密不在通用安装包，需核对邻居/FDB/接口/无线关联/ACL；MAC可仿冒，不当强身份认证。

## 如何选择与部署

按自己的设备单独配置，见[兼容与交付范围](../compatibility.md)。不分发维护者凭据、免密名单或定向二进制。

```text
我选择 F50-OpenWrt-Dashboard 的 management-access 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

无痕允许/拒绝/错误密码、ACL、普通密码登录、USB与Wi-Fi范围分别验证。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
