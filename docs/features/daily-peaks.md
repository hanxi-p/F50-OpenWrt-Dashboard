# 每日下载/上传峰值

[返回功能目录](../../README.md#功能目录) · 功能ID：`daily-peaks` · 数据展示记录

## 这项功能做什么

今日下载/上传峰值常显，不展开历史曲线。

分别保存上下行采样最大值和发生时间；后台保留100天，页面保留今日数值。

## 可以设置/需要准备什么

按北京时间归日；旧日期无记录留空，不补造峰值。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 daily-peaks 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

新峰值、午夜、缺日期、重启保留与写盘失败；三种宽度对齐。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
