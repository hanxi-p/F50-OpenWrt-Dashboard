# 管理与个性化配置

[返回功能目录](../../README.md#功能目录) · 入口ID：`configuration`

在这一个入口选择需要的配置，不必把管理选项当作多套功能分别安装。每项使用自己的设备和参数，未选项保持现状。

## 选择配置项

| 选择 | 可以配置什么 | 详细说明 |
| --- | --- | --- |
| 指定设备后台免密 | 允许名单、Wi-Fi/USB范围，其他设备继续密码登录 | [配置方法](trusted-login.md) |
| SSH密钥登录 | 生成/复用专用密钥、公钥授权与SSH别名 | [配置方法](ssh-key.md) |
| 后台会话时长 | 登录空闲期限，例如12小时 | [配置方法](session-timeout.md) |
| SMTP邮箱参数 | 发件邮箱、SMTP/TLS、收件人和授权码 | [配置方法](../sms-email.md) |
| 代理与订阅 | 插件、订阅/规则、DNS和IPv6策略 | [配置方法](proxy-configuration.md) |
| RPC兼容性适配 | 匹配构建/ABI、服务级库加载与恢复 | [适配方法](rpcd-compatibility.md) |

这些是统一入口内的可选参数与适配项。短信转发服务、代理快捷开关等运行功能仍可从功能目录选择；在这里填写它们需要的个人参数。

## 交给codex的选择示例

```text
请配置 F50-OpenWrt-Dashboard 的“管理与个性化配置”。
本次选择：指定设备后台免密、SSH密钥登录、12小时后台会话。
先核对现有设置和管理连接，按我的设备信息配置；未选项保持现状。
个人设备名单、密钥、邮箱授权码、订阅及实际配置结果只保存到我的本机和设备私有文件。
公开资料只保留功能、方法和通用示例。完成后检查允许/拒绝设备、新SSH连接与会话期限，保存恢复方法。
```

机器可读选择方式见[选择清单示例](../../selection.example.json)：选择`configuration`，再在`configuration.options`填写选项ID。

## 准备、检查和恢复

1. 保存现有配置与可用管理连接，再准备使用者选定的选项。
2. 按各项实际依赖配置，不预置任何个人名单、凭据或订阅。
3. 分别记录明显错误、权限/状态与异常恢复逻辑、多轮场景测试；真实等待会话期限单独记录。
4. 交付使用者自己的结果、原件位置和恢复命令，不把个人配置发布到公开仓库。
