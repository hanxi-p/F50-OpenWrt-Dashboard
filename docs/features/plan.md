# 套餐总量、已用和剩余

[返回功能目录](../../README.md#功能目录) · 功能ID：`plan` · 流量套餐

## 这项功能做什么

自己填写套餐总量与已用，显示进度和剩余额度。

仅“设置流量套餐”编辑；只改总量不动已用，编辑已用保存校准差；次月沿用总量，原始记录保留；1GB=10^9字节。

## 可以设置/需要准备什么

填写本人套餐额度；总量0不算百分比，校准值以本人确认的运营商记录为依据。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 plan 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

总量单改、已用校准、非法输入、并发保存、跨月；不得擅自扣除历史大额记录。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
