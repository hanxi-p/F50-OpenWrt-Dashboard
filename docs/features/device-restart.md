# 重启设备与二次确认

[返回功能目录](../../README.md#功能目录) · 功能ID：`device-restart` · 快捷指令

## 这项功能做什么

防止误点导致整机重启。

点击先确认，取消不执行；确认后执行整机重启，等待管理与后台恢复。

## 可以设置/需要准备什么

保存原状态与回退材料；不要为凑测试轮数反复断电。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 device-restart 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

三轮取消不执行；真实重启另行核对默认系统、AP/SSH/后台与持久数据。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
