# 内网测速与国内／国外连通检测

快捷控制中，“更多设置”所在行的下一排提供三个测速按钮，和现有按钮使用相同字体、尺寸与居中布局。蓝底白字，正在运行的按钮绿底白字；结果直接替换按钮名称。

- **内网测速**：当前打开面板的设备与 F50 之间下载／上传各约5秒，按钮只显示两行“下载 速率”“上传 速率”，没有用时、完成提示或停止按钮。不写闪存、不消耗蜂窝流量；包含HTTP及CPU处理开销，不是无线协商速率或公网带宽。
- **国内测速**：F50 对 `www.baidu.com` 发3次IPv4 ping，按钮显示 `Baidu XX.XX ms`。
- **国外测速**：F50 对 `www.google.com` 做相同检查，显示 `Google XX.XX ms`。无有效ICMP响应显示“无法连接”；Fake-IP不提供真实往返时间，不能拿HTTPS耗时冒充ping。

检测只在点击时运行，不做后台周期测速。ping失败不能证明网页不可用。速率沿用B/s、K/s、M/s、G/s，B为整数，其余两位；不改代理、DNS、网络与加速。

授权RPC发放192位随机凭据；内网端点固定8MiB、单请求15秒，凭据30秒／2GiB预算，互斥传输。前端25秒总超时，页面卸载终止请求，坏数据与网络错误恢复蓝底；不开放匿名无限下载端点。数据及状态仅RAM。包需现有f50-bounded、ucode、flock、ping与jshn。

部署前备份，先安装端点与前端模块，最后更新首页及缓存；检查记录与未测边界见[维护记录](../reviews/2026-10-29-network-test.md)。
