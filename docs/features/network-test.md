# 内网测速与国内／国外连通检测

快捷控制第二排提供内网速度／国内延迟／国外延迟。标题保留，结果使用较小字体，按钮以三行居中显示；蓝底白字，运行时绿底白字。完成或失败后，再点击只复位为初始标题，下一次点击重新测速，不需要刷新页面。

- **内网测速**：当前打开面板的设备与 F50 之间下载／上传各约5秒，按钮显示“内网速度／上传 速率／下载 速率”三行，没有用时、完成提示或停止按钮。不写闪存、不消耗蜂窝流量；包含HTTP及CPU处理开销，不是无线协商速率或公网带宽。
- **国内测速**：F50 对 `www.baidu.com` 发3次IPv4 ping，三行显示“国内延迟／Baidu／Ping XX.XXms”。
- **国外测速**：F50 对 `www.google.com` 做相同检查，三行显示“国外延迟／Google／Ping XX.XXms”。无有效ICMP响应显示“无法连接”；Fake-IP不提供真实往返时间，不能拿HTTPS耗时冒充ping。

检测只在点击时运行，不做后台周期测速。ping失败不能证明网页不可用。速率沿用B/s、K/s、M/s、G/s，B为整数，其余两位；不改代理、DNS、网络与加速。

授权RPC发放192位随机凭据；内网端点固定8MiB、单请求15秒，凭据30秒／2GiB预算，互斥传输。本次任务用所有者凭据释放后立即允许重测，未释放任务最多30秒失效，不保留旧15秒固定冷却。prepare、ping与finish均需授权；其他任务的旧凭据不可释放新任务。前端25秒总超时、RPC另有有界超时，页面卸载终止请求，坏数据与网络错误恢复蓝底；不开放匿名无限下载端点。数据及状态仅RAM。包需现有f50-bounded、ucode、flock、ping与jshn。

部署前备份，先安装端点与前端模块，最后更新首页及缓存；检查记录与未测边界见[维护记录](../reviews/2026-10-29-network-test.md)。
