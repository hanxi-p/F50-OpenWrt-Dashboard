# 内网测速与国内／国外连通检测

首页快捷控制首排下方提供三个按需按钮，结果用小字显示在各自按钮下方，关闭后不在后台周期测速。

- **内网测速**：当前打开面板的设备与 F50 之间的 HTTP 下载／上传吞吐量，各约4秒、每方向最多128MiB。使用内存数据，不写闪存、不消耗蜂窝流量；包含浏览器、HTTP、CPU和无线处理开销，不能当作无线协商速率或公网带宽。结果沿用 B/s、K/s、M/s、G/s，B为整数，其余两位小数。支持停止及25秒页面总超时。
- **国内测速**：F50 对 `www.baidu.com` 发3次 IPv4 ping，同时检查 HTTPS 响应时间。
- **国外测速**：F50 对 `www.google.com` 做相同检查。若代理DNS返回 `198.18.0.0/15` 虚拟地址，会明确显示无法测真实ICMP，单列HTTPS结果；ping失败不等同网页不可用。

ping显示平均往返延迟和丢包率。HTTPS时间包含连接、TLS及首个页面响应，可能经过现有代理；这两个数值含义不同，也不是手机到网站的完整延迟。站点不接受ICMP、DNS或当前出口异常都会影响结果。功能不改变代理、DNS、网络和硬件加速设置。

RPC只有固定目标，无任意地址或命令输入。测速凭据由已授权的 LuCI RPC 创建，192位随机值、30秒有效、每次最多512MiB，单请求8MiB／15秒，互斥传输；结果与临时状态只在RAM。匿名、过期、尺寸错误和超额请求被拒绝，不开放匿名无限下载端点。包需现有 `f50-bounded`、ucode、curl、flock、ping与jshn。

部署前备份首页、缓存模板和受影响文件。先安装RPC、ACL及流端点和前端模块，最后更新首页及缓存；只重载rpcd，不重启Wi-Fi。代码／SSH验收与未测边界见[维护记录](../reviews/2026-10-29-network-test.md)。
