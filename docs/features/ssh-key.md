# SSH密钥登录

[返回功能目录](../../README.md#功能目录) · 功能ID：`ssh-key` · 可选配置

## 功能

为自己的电脑配置SSH公钥登录和连接别名。

在使用者电脑生成或复用专用Ed25519密钥，只将公钥导入F50；可以设置SSH Host别名，之后使用ssh f50连接。私钥留在电脑，可结合ssh-agent管理口令。

密钥由使用者自己生成，公开文档只提供配置方法。已有同名密钥不覆盖；核对设备主机指纹，并保留当前管理连接完成新连接验证。

## 需要使用者提供的选项

电脑的SSH工具、F50管理地址、当前登录方式，以及是否需要密钥口令和Host别名。

## 验收

新终端三轮密钥连接、主机指纹及Host别名；未授权密钥不能登录，原有回退连接保持可用。
