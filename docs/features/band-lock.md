# 制式与频段锁定

[返回功能目录](../../README.md#功能目录) · 功能ID：`band-lock` · 快捷控制

## 这项功能做什么

在更多设置查看邻区并锁定制式/频段。

保留锁定、保存并应用、保存、复位；显示有效目标与错误，不在页面底部另占一组；选基站列表不重复频点。

## 可以设置/需要准备什么

先记录原制式和锁定配置；不猜AT参数，不改变设备标识。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 band-lock 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

正常/错误/忙状态、有限等待和恢复原配置；无信号单列。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
