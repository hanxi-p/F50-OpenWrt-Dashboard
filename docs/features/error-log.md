# 报错与操作日志

[返回功能目录](../../README.md#功能目录) · 功能ID：`error-log` · 诊断管理

## 这项功能做什么

保留操作结果、错误原因和故障上下文，容量5GB。

events/errors/system/state分开；4MiB分片不只留上一份；不按天数过期，容量满清最旧记录；约15秒收集，活动文件边界可暂时小量超额。

## 可以设置/需要准备什么

原文只留设备/私人备份；公开前脱敏，停止日志服务不删除已有记录。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 error-log 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

三轮分片不覆盖、容量、同日清理、队列溢出、权限/启停与错误标签收录。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
