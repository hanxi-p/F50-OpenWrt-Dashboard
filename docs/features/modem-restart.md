# 重启调制解调器

[返回功能目录](../../README.md#功能目录) · 功能ID：`modem-restart` · 快捷控制

## 这项功能做什么

只重启蜂窝模块，保留本地管理入口。

与整机重启独立，恢复后重新核对SIM、注册与数据连接；失败显示实际状态。

## 可以设置/需要准备什么

记录原蜂窝状态与插件组合，保留USB管理。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 modem-restart 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

确认触发路径和恢复后注册/DNS/后台；实际重启按当前任务安排，未执行写未测。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
