# 四传感器温度

[返回功能目录](../../README.md#功能目录) · 功能ID：`temperature` · 数据展示记录

## 这项功能做什么

大字号平均温度，框内列出四个传感器。

SoC、CPU、调制解调器和主板分别左对齐；平均值只使用有效传感器读数，不代替芯片结温测量。

## 可以设置/需要准备什么

选择展示与核对；不自动开启休眠或关闭热点。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 temperature 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

对照有效传感器读数与平均值，缺失/异常字段不显示假0。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
