# 本次累计接收/发送

[返回功能目录](../../README.md#功能目录) · 功能ID：`session-usage` · 流量与套餐

## 这项功能做什么

分别显示当前蜂窝接口收到和发出的总字节数。

接收/发送独立卡片，来自sipa_eth0原始计数；接口重建可能归零，与运营商月套餐周期分开。

## 可以设置/需要准备什么

统计当前蜂窝接口，不把Wi-Fi/USB转发再次累加。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 session-usage 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

比较/sys计数与显示换算，重启/接口重建后不出现负差或回绕假流量。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
