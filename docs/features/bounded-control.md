# 超时、锁与子进程清理

[返回功能目录](../../README.md#功能目录) · 功能ID：`bounded-control` · 诊断管理

## 这项功能做什么

避免控制任务无限等待、重复切换或留下孤儿任务。

PID+启动时间识别锁持有者；异步交接与清理；限时取消子进程，成功初始化保留必要后台任务。

## 可以设置/需要准备什么

按风险清单检查受影响入口，不自动增加整机看门狗或诱发真实内核卡死。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 bounded-control 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

三轮活锁/陈旧锁/迟到响应/TERM无响应/脱离子进程；控制后无残留并恢复原状态。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
