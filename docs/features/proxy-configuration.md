# 代理与订阅配置

[返回功能目录](../../README.md#功能目录) · 功能ID：`proxy-configuration` · 可选配置

## 功能

选择代理插件、导入自己的订阅或规则，并配置DNS与IPv6。

可按需安装OpenClash与匹配核心，导入使用者自己的订阅/配置、规则或备份，再配置代理模式、DNS与IPv6策略。面板中的OpenClash快捷开关是独立功能，可一起选择。

公开仓库提供操作流程与兼容检查；订阅地址、节点凭据、控制口令和个人规则留在使用者的设备或私有存储。与AdGuard组合时按实际端口协调DNS。

## 需要使用者提供的选项

使用者选择的插件、订阅/配置来源、是否启用AdGuard以及IPv6需求。

## 配置方法

从[OpenClash官方项目](https://github.com/vernesong/OpenClash)核对适配版本，在使用者设备上安装并导入其提供的配置；保留原配置和恢复入口。

```text
我选择 F50-OpenWrt-Dashboard 的 proxy-configuration 功能。
先读取此功能页与风险清单，核对我的系统、现有配置和选项；为我的设备准备配置，保留备份。
公开资料只用通用说明与示例；设备名单、凭据、密钥和实际配置保存到我的本机或设备私有文件。
配置后按功能页检查，交付结果和恢复方法。
```

## 验收

配置校验、核心/防火墙/DNS、代理与直连、IPv6，以及与AdGuard三轮四组合；测试后恢复使用者所选状态。

分别记录语法/配置、逻辑和多轮场景；通过、失败和未测留在使用者的执行记录中。恢复使用本次配置前保存的原件与状态。
