# 无线失败命令追踪

[返回功能目录](../../README.md#功能目录) · 功能ID：`wireless-trace` · 定向诊断

## 这项功能做什么

记录无线初始化究竟是哪条命令失败。

对匹配mac80211 ucode脚本记录命令/退出码；wdev只记安全标签；已定位距离设置-12，但不把它当系统OOM或驱动已修复。

## 可以设置/需要准备什么

先保存原脚本与核对布局；不是默认安装步骤，不自动重启热点。

## 如何选择与部署

这是按实际故障选择的诊断工具，见[故障排查](../troubleshooting.md)；不是首页安装器的自动步骤。

```text
我选择 F50-OpenWrt-Dashboard 的 wireless-trace 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

声明顺序与真实调用路径、日志持久收录、三轮重载；手机/冷启动单独验收。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
