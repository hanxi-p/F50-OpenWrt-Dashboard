# DNS协调与恢复

[返回功能目录](../../README.md#功能目录) · 功能ID：`dns-recovery` · 诊断管理

## 这项功能做什么

在代理、广告过滤和直连之间协调可用解析链。

常用53→5353→7874；有限等待、串行改配置、健康探测与失败回退；插件升级后需核对守护是否覆盖适配。

## 可以设置/需要准备什么

按本人已装端口与配置检查；公网故障与本地DNS监听分开判断。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 dns-recovery 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

三轮四组合、故障注入、服务PID互不重启、解析/HTTPS与恢复初始组合。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
