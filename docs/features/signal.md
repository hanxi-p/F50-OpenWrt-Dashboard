# 信号与网络质量

[返回功能目录](../../README.md#功能目录) · 功能ID：`signal` · 数据展示记录

## 这项功能做什么

制式、运营商、频段、QCI和信号读数集中展示。

显示4G/5G SA、运营商简称、频段/带宽；RSRP、RSRQ与SINR常显；QCI与AMBR同列，AMBR是网络下发上限，不是实测速率。

## 可以设置/需要准备什么

沿用当前SIM与注册状态，不主动改变网络或搜基站。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 signal 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

对照新鲜蜂窝状态；无信号/缺字段时不伪造数值。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
