# 月度用量历史

[返回功能目录](../../README.md#功能目录) · 功能ID：`monthly-history` · 流量与套餐

## 这项功能做什么

查看每月接收、发送和含校准的已用合计。

点击月份进入月度列表；RX+TX+该月校准与当前月卡片一致；月历史与每日原始统计分开存储。

## 可以设置/需要准备什么

保留自己的历史库，更新不重建空库。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 monthly-history 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

同月重复记录求和、跨月、调整值和数据库失败。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
