# 指定设备后台免密

[返回功能目录](../../README.md#功能目录) · 功能ID：`trusted-login` · 诊断管理

## 功能

选择可免密进入后台的设备，其余设备继续使用密码。

使用者选择设备名称和连接方式，提供该网络下实际使用的MAC地址；手机开启私有/随机MAC时，使用该F50网络对应的地址。Wi-Fi和USB授权范围分别设置，也可以只允许指定电脑经USB免密。

名单和访问策略保存在使用者设备上，不提供预置的个人名单。免密判断应核对请求来源、邻居记录、桥接端口与无线关联/授权状态，保留普通密码登录、会话与RPC权限检查。MAC可仿冒，此功能适合可信局域网内的便利访问。

## 需要使用者提供的选项

使用者选择的手机/电脑、当前MAC、Wi-Fi或USB范围；其他设备登录后的会话时长可另选“后台会话时长”。

## 配置方法

保存现有LuCI认证文件与配置，再按当前版本适配指定设备策略。没有选择任何设备时保留密码登录，不自动允许所有曾连接设备。

```text
我选择 F50-OpenWrt-Dashboard 的 trusted-login 功能。
先读取此功能页与风险清单，核对我的系统、现有配置和选项；为我的设备准备配置，保留备份。
公开资料只用通用说明与示例；设备名单、凭据、密钥和实际配置保存到我的本机或设备私有文件。
配置后按功能页检查，交付结果和恢复方法。
```

## 验收

三轮允许名单/非名单、错误密码、伪造转发头与接口串用；允许设备无痕访问成功，其他设备仍需密码；RPC权限与退出登录路径正常。

分别记录语法/配置、逻辑和多轮场景；通过、失败和未测留在使用者的执行记录中。恢复使用本次配置前保存的原件与状态。
