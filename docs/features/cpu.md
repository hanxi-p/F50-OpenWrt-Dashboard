# CPU总负载与逐核心详情

[返回功能目录](../../README.md#功能目录) · 功能ID：`cpu` · 界面与设备

## 这项功能做什么

总占用常显，点开查看8个核心占用与频率。

详情在CPU占用卡片内展开；当前能效模式的离线核心与性能模式的在线核心按实际状态显示。

## 可以设置/需要准备什么

只展示状态；需要改核心使用时另选性能/能效功能。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 cpu 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

比较总/逐核读数，核对online与频率；展开收起不发出模式切换。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
