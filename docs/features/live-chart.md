# 实时下载/上传双曲线

[返回功能目录](../../README.md#功能目录) · 功能ID：`live-chart` · 数据展示记录

## 这项功能做什么

最近5分钟、约2秒采样，关掉网页也继续记录。

白底天蓝下载/青绿上传，上下分区共同比例尺；动态纵轴、首尾时间和上下峰值对称；手机/桌面占用空间分别约200/230px。

## 可以设置/需要准备什么

保持既有蜂窝接口；不自动发起测速或大文件下载。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 live-chart 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

空闲、单向、上下悬殊、单位切换；后台采样不依赖网页，旧缓存不当实时。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
