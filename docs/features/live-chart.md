# 实时下载/上传像素图

[返回功能目录](../../README.md#功能目录) · 功能ID：`live-chart` · 数据展示记录

## 这项功能做什么

默认显示最近1分钟，横向拖动查看过去5分钟；拖回最右侧或点击“回到实时”继续跟随。约1秒采样，关掉网页也继续记录。页面默认每秒读取缓存，较重的信号快照仍约6秒采集一次；请求串行，按请求耗时补偿刷新间隔。

白底天蓝下载/青绿上传，上下分区共同比例尺；采用持续帧动画移动曲线组，不随每秒数据到达重建SVG或重启动画。图形采用轻度短窗口平滑（时间常数1.4秒），保留采样起伏并减轻噪点，实际数字、原始峰值和用量累计不平滑、不改写；采样点之间使用水平保持、垂直换值的阶梯轮廓，配合像素填充；阶梯没有斜向尖峰或圆滑样条，也不会额外制造峰值。动态纵轴、首尾时间和上下峰值对称，手机/桌面占用空间分别约200/230px。

外观沿用仿btop的蓝绿像素填充和细轮廓；显示时钟缓冲约1秒（1.2秒），不超过已知采样时间。曲线段只依赖已知端点与过去数据，后续新点不会重新弯折已经显示的前一段，减少右侧补点跳动。

隐藏页面、离开首页或数据停止更新后停止动画；系统要求减少动画时只更新静态图。历史拖动不增加RPC或AT查询，手指纵向滑动仍用于网页滚动。

## 可以设置/需要准备什么

保持既有蜂窝接口；不自动发起测速或大文件下载。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 live-chart 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

空闲、单向、上下悬殊、单位切换；后台采样不依赖网页，旧缓存不当实时。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
