# 手机与桌面布局

[返回功能目录](../../README.md#功能目录) · 功能ID：`mobile-layout` · 其他功能

## 这项功能做什么

常用信息常显，详情按需展开，手机按钮每行3个。

大字号下载/上传与今日峰值左右对齐；实时图与峰值图手机约200px、桌面约230px；更多设置有独立展开背景。

## 可以设置/需要准备什么

保留现有SSID、密码、地址与套餐；确认手机和桌面宽度。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 mobile-layout 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

检查320/390/768布局、对齐、展开收起与无页面横向溢出。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
