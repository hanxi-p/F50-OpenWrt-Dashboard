# 切换到Android

[返回功能目录](../../README.md#功能目录) · 功能ID：`android-switch` · 快捷控制

## 这项功能做什么

更多设置中主动进入保留的原厂系统。

二次确认后走配套mu300-next-boot路径；两套管理地址分开，返回Linux使用既有Android Root入口。

## 可以设置/需要准备什么

先确保自己的Android启动链与返回方法正常。

## 如何选择与部署

此功能使用[共享面板基础包](../install.md)。选择此项确定配置和验收范围；基础包会一并部署共用页面、RPC及采集服务，执行前由codex列出依赖与会一并安装的内容。

```text
我选择 F50-OpenWrt-Dashboard 的 android-switch 功能。
先读对应功能页、依赖和风险清单，保存原配置；列出会配置/安装的范围后按我的选择推进。
按本页验收并记录通过、失败与未测，最后交付恢复入口。
```

## 怎么验证

取消无副作用；实际切换与回Linux需单独安排，不由页面点击模拟代替。

按[风险清单](../risk-register.md)分别记录明显错误、逻辑审查和多轮场景测试。已有历史验证不替代自己设备上的验收，危险或需人工配合场景单列未测。
