# RPC兼容性修补

[返回配置入口](configuration.md) · 选项ID：`rpcd-compatibility` · 可选配置

## 功能

按系统版本适配rpcd依赖库，处理已确认的回调兼容问题。

这是可选的兼容性修补：先核对rpcd、libubox构建、ABI和故障日志，再选择匹配源码进行构建与隔离验证；可将匹配库限定为rpcd服务加载，保留系统其他服务使用原库。

库文件本身是软件构建产物；设备版本、服务加载路径和具体构建需要逐台核对。公开内容提供来源、适配流程和验收方法，不分发未经适配的通用二进制。

## 需要使用者提供的选项

系统/架构、rpcd与libubox版本和哈希、原错误上下文、可用SSH及原件备份。

## 配置方法

按[故障修补说明](../troubleshooting.md)核对上游修复与ABI，先做隔离测试，再按实际兼容结果选择部署方式。此选项不等于全量升级系统库。

```text
我选择 F50-OpenWrt-Dashboard 的 configuration 入口，配置 rpcd-compatibility 选项。
先读取此功能页与风险清单，核对我的系统、现有配置和选项；为我的设备准备配置，保留备份。
公开资料只用通用说明与示例；设备名单、凭据、密钥和实际配置保存到我的本机或设备私有文件。
配置后按功能页检查，交付结果和恢复方法。
```

## 验收

导出符号/ABI、隔离缺陷复现与修补对照、rpcd实际加载路径、三轮插件组合与对象存活；失败恢复原服务配置和原库。

分别记录语法/配置、逻辑和多轮场景；通过、失败和未测留在使用者的执行记录中。恢复使用本次配置前保存的原件与状态。
