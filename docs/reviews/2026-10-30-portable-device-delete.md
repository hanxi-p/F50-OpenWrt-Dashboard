# 补齐通用面板设备删除（R129）

0.3.1 迁移了设备档案，却遗漏 F50 的删除菜单和删除处理链路。0.3.2 点击无线设备的“总累计”先进入设备操作，提供删除记录和原档案入口。删除需要二次确认，并核对当前 UUID；虚拟有线汇总不作为一台真实设备删除，避免误清整个 LAN 组。四区样式不变。

新增写权限 RPC 和串行请求 worker，复用档案操作锁，RPC 不修改账本；由唯一采集器归档并清理该设备及确认关联 MAC。删除请求重复提交保持幂等，不覆盖旧归档；删除状态变化立即保存，降低分钟检查点重启后重新出现旧记录的风险。当前连接期间隐藏，成功观察到离线再上线后从新基线统计；失败扫描不认作离线，系统 boot 代次变化可识别观察中断。名称、UUID、MAC关系和整体 WAN 历史保留，不断开网络。删除期间阻止相关档案改绑，防止更换归属绕过删除。

验证在 F50 的独立临时账本/档案目录执行通用包 ucode：三轮归档/关联组删除、其他设备保留、重复采样、失败扫描、离线重连及新基线；请求夹具验证确认、陈旧身份拒绝、重复提交、原账本/档案不被 RPC 修改、删除期间改绑防护及重连后再次删除。菜单 DOM 三轮验证确认/取消、RPC参数、原档案入口、错误恢复和清理，既有样式与生命周期回归通过。未删除真实设备，也未将 F50 上的隔离执行表述为 AX6S 实机部署。

编译离线包与旧版备份保留本地，公开仓库只发布源码与通用说明。不把无线拒绝连接能力或删除虚拟有线汇总声称为此次已实现。

0.3.2最终候选包完成三轮隔离新装、重复/热更新、代码回退及健康失败自动恢复，检查删除worker具有执行权限、RPC已注册remove。交付包逐成员与候选包一致并核验内外摘要，旧版0.3.1保留本地；AX6S实际部署仍待接入目标设备验收。
