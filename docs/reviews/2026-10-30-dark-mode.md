# 深色主题残留修复（R131）

Aurora已切换至深色时，部分快捷按钮、更多设置面板及流量图表仍使用白色背景。修复保持现有控件与操作逻辑，将普通未选中状态接到surface、text和hairline，展开态使用brand-subtle，重启按钮使用danger；图表网格、零线及游标沿用主题线条色。每日用量图容器及回到实时按钮使用带原有颜色回退值的主题变量。

## 范围与兼容

仅修改extras/dashboard/home.js、f50livechart.js及f50quota5.js中的样式，并更新SHA256SUMS。沿用现有html[data-darkmode=true]主题标记；不新增主题自动检测、服务、RPC或定时器。保留现有按钮、布局和事件，包括延迟检测；未合入其他本地功能定制。

普通深色按钮覆盖排除.on、aria-pressed=true、aria-expanded=true、data-mode、data-target-mode及data-running=true，避免覆盖开启、模式切换和延迟检测运行颜色。对没有主题变量的环境保留回退颜色；其他主题仍需按其变量和标记适配。

## 验证

- npm test：既有三轮页面DOM和42种尺寸的实时曲线测试通过，覆盖折叠、刷新、鼠标/触摸及卸载。
- 三轮选择器检查：未选中按钮在深色命中，浅色不命中；开启、展开、性能模式、切换中和检测运行态不被普通背景覆盖。
- 本机Chrome：基于上游模板/样式和脱敏示例的夹具进行三轮明暗切换，查看图表背景、每日用量容器与展开/关闭按钮；活动开关和能效颜色仍可区分。夹具未加载完整Aurora布局，因此不是整页像素或真实设备业务验收。
- Python包清单与安装映射检查：按仓库工具执行；SHA256SUMS与当前源文件一致。

本次没有重新部署到设备，也没有触发Wi-Fi、代理、重启或其他系统控制。真实手机触摸、全部第三方主题与长期运行未在本轮验证。回退时将上述三个源文件与SHA256SUMS恢复为更新前版本，并按安装说明部署及刷新资源版本。
