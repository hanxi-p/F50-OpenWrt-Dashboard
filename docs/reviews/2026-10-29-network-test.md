# 2026-10-29 按需网络测速（R101）

快捷控制首排下方新增内网、国内、国外三个按钮，结果为按钮下方小字。国内／国外经使用者确认是百度／谷歌延迟检测，内网吞吐单列。沿用既有按钮、折叠箭头和速率单位，不修改设备统计、负载模块或网络配置。

## 实现与边界

LuCI授权RPC发放192位随机短期凭据；HTTP POST流端点只接受固定8MiB方向与尺寸，30秒／512MiB预算，15秒单次超时和互斥锁。数据仅RAM，前端每方向4秒／128MiB上限，25秒总超时及停止；页面卸载终止请求。只在按下时执行，不运行周期测速。ping只允许两个枚举目标，每次3包与有界子进程；HTTPS HEAD同时核对curl成功和HTTP状态码，不把超时后的200当作完成。

百度／谷歌检测从F50发起，HTTPS可沿用既有代理。Google Fake-IP不代表真实ICMP地址，前端单列说明，不能把代理可用性称为直连ping或下载带宽。内网结果是当前终端与F50的HTTP吞吐，包含CPU和HTTP开销，不是PHY或iperf极限。

## 验证

- 原生三轮固定大小双向流、错误凭据、方法、过期、超额、互斥拒绝；ucode入口编译与shell语法检查。
- 三轮DOM／运输桩：快捷控制挂载、分列小字结果、国内／国外解析、Fake-IP说明、双向流和错误恢复／卸载；不冒充浏览器视觉或手机触摸验收。
- 实际电脑Wi-Fi三轮HTTP双向传输，检查实际接收长度和上传确认字节；同步采样CPU、接口错误及恢复空闲。具体速率与私人运行日志留本机，不当作所有设备保证值。
- HTTP入口拒绝匿名／错误凭据；授权RPC的固定目标与无效输入、两站各三轮及活动JS内容读回，安装映射核对。测试临时会话销毁，不改用户会话或免密名单。
- 备份后仅增量部署、缓存更新与rpcd重载；启动ID、网络、无线、防火墙、代理恢复策略、认证与套餐配置保持不变。未重启路由器、关加速或修改CPU模式。

初次测试发现系统PATH无timeout、uhttpd不转发任意自定义HTTP头；改为既有有界进程助手与专用Content-Type携带短期凭据，不把凭据放URL。尝试另一timeout实现会让监视进程继承锁，已撤回。流结束与子进程清理有短暂交叠，客户端有界重试409。测试脚本的默认编码、变量名与shell参数错误已修正，失败保留在私人记录；均不当作设备原有故障。

持续下载CPU增加可来自无线、中断、TCP／代理及本次HTTP测试处理；load average不是CPU百分比，按 `/proc/stat` 时间增量计算（[Linux内核说明](https://docs.kernel.org/filesystems/proc.html)）。当前能效模式和瞬时业务会影响结果，短时通过不代表高温、弱信号或长期满负载已验收；既有EDMA回压及充电警告仍保留。
