# 2026-10-29 三行测速与复位重测（R104）

三个测速按钮位于快捷控制第二排，后面仍是AdGuard／重启／更多设置。初始标题分别为内网速度、国内延迟、国外延迟；结果保留标题和两行小字，内网按上传／下载排列，站点按Baidu或Google／Ping数值排列。失败保留标题与站点，结果写无法连接；无用时、完成或停止控件。完成／失败后点击只复位，再点击开始新测试；不因复位发送新的网络请求。

内网上下各约5秒、数据端点大小和总预算不变。原15秒固定冷却与约10秒测速不匹配，改为有界任务所有权：prepare生成凭据，finish需授权且匹配当前凭据，互斥锁内撤销。活跃任务不能被其他prepare覆盖，过期仍30秒自动失效。错误／旧凭据不能释放新任务；传输结束清理交叠时前端短暂有界重试释放，不移除字节与时间上限。

前端分别限制prepare、ping、finish等待，整体仍有25秒传输超时，卸载中止请求；完成、错误和超时均恢复可操作蓝底，不将HTTPS耗时当ping。三轮DOM每轮两次测速／复位、三行标题／速率、第二排顺序、失败和超时后复位通过；既有设备统一表、折叠、20行完整展开和滚动回归通过。DOM不代表真实手机视觉验收。

原生三轮固定块、尺寸／过期／预算／互斥以及释放／立即新任务／旧凭据拒绝通过。HTTP授权会话三轮快速准备、8MiB传输、释放、立即重测通过，释放后旧凭据403，匿名finish被拒绝；测试临时会话销毁。上传／下载5秒传输算法未改，本轮不重复持续带宽测试，不以8MiB快速任务冒充5秒带宽验收。

修改前备份RPC、ACL、前端与缓存模板，增量部署三文件，更新缓存并只重载rpcd。活动JS内容与安装映射核对，网络、无线、防火墙、认证、套餐与启动ID不变；未重启路由器或其他服务，不改账本、USB识别或驱动。当前规则取代此前按钮位置、纯结果标签和固定冷却的说明，历史记录保留。
