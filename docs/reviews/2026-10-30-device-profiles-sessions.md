# 设备档案、MAC 历史和 Wi-Fi 会话（R125、R126）

设备档案采用 UCI 持久 UUID，MAC 为可确认绑定、解绑的成员。首次迁入已有名称和明确的单层身份关联；陌生 MAC 单独建档，不按主机名、IP、厂商或连接时间猜测归属。分 MAC 的原始流量始终独立保存，按档案汇总；解绑及绑定不清零、不重复累计，不改变免登录权限。

UCI 为权威配置，JSON 为派生缓存。仅发现新成员或人工操作时保存 UCI，避免每秒重写。修改共用设备操作锁，并以独立随机临时包名隔离默认 UCI 待提交内容。包含期望档案 ID 和确认字段，拒绝陈旧页面和未确认请求；已拒绝连接的档案须先解除拒绝才能移动成员。配置截断、缺少原有成员时保留缓存并拒绝覆盖；缓存或 UCI 单独缺失可从另一份有效副本恢复 UUID。

主面板布局不变，“总累计”的原菜单增加档案入口；档案内管理 MAC、绑定历史和 Wi-Fi 连接记录。行按档案 UUID 复用，当前代表 MAC 改变时保留行及滚动位置。编辑名称仍使用原入口。

会话复用已有每秒 Wi-Fi 检测，不新增扫描进程；成功检测连续缺席三次才关闭会话，检测失败不判掉线。接口改变单独记录；采集空档、重启或时钟回退明确记为观察中断，不能声称精确知道断开时刻。连接时间为观测时间，不能当成认证证据，也不能识别随机 MAC 的真实持有人。日志按大小轮换，保留当前和上一代；小型活动状态每分钟及连接变化时落盘，正常连续采样不每秒写历史。会话写入失败不阻断流量计数。

三轮 UUID/旧映射迁入/同名不合并/重复操作/解绑锚点/原始总量守恒模型、Unicode 名称及 UCI 隔离夹具通过。会话模型覆盖重复、失败检测、缺席防抖、重连、接口变化、采集重启和空档；管理弹窗 DOM、原设备菜单、整页及便携包 UI 回归通过。F50 增量部署先备份，仅重启账本实例并重载 rpcd；原生计数源 PID/代次、有效历史和网络/无线/登录配置保持，活动文件与 HTTP 资源摘要匹配，实际 RPC 和多轮刷新正常，相关错误日志未发现新增错误。匿名档案读取、绑定请求无权限。不以模型代替真实客户端反复断连或断电测试。

## nlbwmon 方案选择

核对 OpenWrt 25.12 包使用的 [Makefile](https://github.com/openwrt/packages/blob/openwrt-25.12/net/nlbwmon/Makefile)，对应上游提交 `29236be687927b0c81ee6e2642e7caa8787c4ad3`。该版本的 [nfnetlink.c](https://github.com/jow-/nlbwmon/blob/29236be687927b0c81ee6e2642e7caa8787c4ad3/nfnetlink.c) 使用 `CT_GET_CTRZERO`，会影响并行的只读高水位采集；其基于原始地址对子网的判断没有现有 F50 采集器的本地 DNS 重定向排除规则。外部目的地址被本地 DNS 接管时，直接替换会改变计数口径。现有原生 IPv4/IPv6、LAN/路由器/DNS 排除、代理客户端段、重置/重复及销毁竞争模型已三轮验证。

因此本版继续使用现有只读后端，nlbwmon 未安装、未启动，也未清零历史。这是对“只有更准确、更稳定才切换”的执行；未做 nlbwmon 的正式负载、硬件卸载及真实重启验收，不将静态审查表述为实机通过。需要采用它时，应先补齐统计口径并独占采集，通过同样测试后再切换。

AX6S 离线源码更新为 0.3.0，保留原有单 WAN、无线逐台及有线汇总的展示；包含档案和会话功能、安装依赖和健康检查。包内不含任何 F50 私有名单、历史或配置。具体编译包与安装验证记录留在本地离线目录，不能把 F50 验证声称为其他 AX6S 固件的实机验收。
