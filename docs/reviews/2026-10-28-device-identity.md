# 2026-10-28 设备地址归属检查

用户在手机设置中明确确认新MAC后，关联已知旧地址；不将名称/厂商相同视为同一设备。私有 identities.json 为“成员MAC → 稳定身份MAC”的单层映射，不随公开包分发。实际地址、名单和账本备份均留本机与设备，不进入仓库。

原始计数仍按MAC计算。日/月/总值只在输出时求和，不把任一历史累计值写入另一个MAC，不合并不同原始计数基线。活动地址优先、最近连接时间用于离线保留，合并行的速率只合计在线成员，名称修改同步已确认成员。直接移除关联即可重新展示各自原始记录，不需要重建账本。关联不自动授予免密；本轮按使用者明确确认迁移指定条目，其余名单保持。

检查：原有账本57项断言通过；三轮新地址/历史合计/当前速率/重复采样/离线/旧地址重连/短时重叠/序列化重启/日月边界/循环关联隔离通过。三轮关联名称修改、清除、恢复及实际邻居/FDB/无线授权下的免密正反匹配通过。实机只显示一条合并设备，合计等于两份原账本之和，实际MAC为已确认的在线地址。

备份后替换 ledger/collector/rpc 三个脚本，仅向 procd 账本实例发信号。原始源进程PID未变，统计计数未重置；现有有效历史保留，设备和无线未重启。原始流量仍按现有采集能力计量，映射不会提高硬件加速路径的计量精度。未真正断电/更改手机设置/人为切换无线，也未使用浏览器，实际客户端显示以刷新后的页面为准。

本轮先上线合并，经使用者后续要求纳入双仓库发布检查。安装器原本备份 /etc/f50-devices/*.json，会包含新增私有映射，恢复脚本继续避免覆盖活动账本。
