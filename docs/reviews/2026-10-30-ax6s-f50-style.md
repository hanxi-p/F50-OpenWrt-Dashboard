# AX6S 四区统一 F50 样式（R127）

0.3.1 将流量、累计数字、设备流量统计、设备负载与温度置于一个 F50 容器，修正原先 WAN 区与设备区各有一套卡片、字号及留白的问题。WAN include 负责唯一的挂载和清理；旧 status include 保留为空兼容入口，避免升级后出现重复面板、重复轮询或闪烁。

以 F50 当前源码为准：设备表格 CSS 仅替换类名前缀；Lato 字体文件、首页和设备源码摘要已与实际 F50 核对。下载/上传 `#249ad1/#159b85`，设备累计 `#8970b3`；标题 `.7rem/600`，下载/上传 `1.7rem/1.4rem`，负载主数字 `1.4rem`，标签 `.68rem`，温度详情桌面 `.65rem`、手机 `.62rem`。累计数字采用 F50 累计区的 `.94rem`，保留今日下载、今日上传、本月累计、总累计四个真实计数；手机两行两列，不添加套餐或比例条。具体参数及 F50 来源摘要见包内 `STYLE-CONTRACT.json`。

卡片底色、语义色和明暗色板使用 F50 Aurora 对应值，范围限于扩展容器；移除强制所有后代使用 Lato 的规则，让曲线的等宽字体保持有效。CPU/内存/温度三卡采用 F50 间距、内边距和字号；AX6S 两核仍直接显示，存储保持折叠，不虚构调制解调器或缺失的温度传感器。有线仍在同表聚合，无线逐台，原档案/MAC/会话及计数后端不变。

验证采用代码、SSH、DOM与CSS契约，不使用浏览器。覆盖四区顺序、唯一卡片、四个计数更新、表格样式来源等价、配色/字号/响应式规则、180轮外部刷新不重新挂载、移除/重建及定时器清理。其他设备表、曲线、资源、档案及折叠回归通过。编译包、旧版备份和隔离安装结果留本地，不将源代码样式核对声称为浏览器逐像素实测或 AX6S 新版实机验收。
