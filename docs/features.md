# 面板功能详解

[返回首页](../README.md) · [安装与Q&A](11-optional-dashboard.md) · [日志与维护](operations.md)

## 1. 信号与蜂窝网络

首页常显当前制式、运营商简称、频段与带宽。QCI 是网络下发的业务等级字段；旁边的上下行上限是网络下发的 AMBR，不能当作实测速率。右侧信号强度与制式同级字号，RSRQ / SINR 辅助判断质量。

展开蜂窝详情查看注册、基站、小区、PCI、频点、地址和 SIM 信息；手机号仅在 SIM 提供该字段时显示，空值不猜测。页面展示状态，不主动扫描或切换附近基站；高铁模式已移除。

## 2. 实时速率与每日峰值

| 项目 | 数据和显示 |
| --- | --- |
| 下载 / 上传 | 同一蜂窝接口接收/发送增量除以采样时间，沿用蓝/绿配色 |
| 实时曲线 | 约2秒采样、5分钟窗口；上下分区但一个像素比例，流量较小的一方向可占较小高度 |
| 动态轴 | 单位和上限随数据变化；零线、网格和曲线使用同一坐标换算 |
| 今日峰值 | 从已有有效样本分别记录下载和上传最大值；不是运行测速 |
| 峰值历史 | 后台保存100天，点击首页标题或数字展开30天；保留1320px横滑，右轴固定 |
| 历史图尺寸 | 手机整体约200px，桌面约230px，与实时图对齐；日期稀疏显示，点位保留详情 |
| 采集与网页 | 网页关闭不停止采集；每日峰值服务每10秒读取已有约2秒样本 |

峰值按北京时间归日，新峰值和日期变化后原子写入 SD；历史未记录的日期留空，不从用量反推速度。服务刚启用时只能记录此后样本，不补造当天此前的峰值。

## 3. 用量与套餐

| 页面字段 | 计算口径 |
| --- | --- |
| 本次累计接收 / 发送 | 当前蜂窝接口的原始字节计数；接口重建可能归零，不等同于运营商账单周期 |
| 本小时使用 | 北京时间本小时的接收+发送 |
| 今日使用 | 北京时间0点至当前已落盘统计的接收+发送 |
| 本月总消耗 | 当前月原始接收+发送，加该月手动校准量 |
| 本月剩余 | 套餐总量减已用；超额单独展示 |
| 百分比 | 已用/总量；总量为0时不计算百分比 |
| 日用量折线 | 点击本月总消耗在首页展开30天，每天附用量数字，不跳子界面 |
| 月度历史 | 点击月份，显示接收、发送与已用合计 |

“设置流量套餐”是唯一编辑入口。只改总量，已用继续累计；编辑已用，保存当月校准差，原始历史不清空。次月沿用套餐总量、使用新月统计。`1 GB = 1,000,000,000 字节`；速率沿用 MU300 的 B/s、KB/s、MB/s 显示，文件下载大小必须先统一单位再对账。

vnStat 周期落盘，可能成批显示增长；每分钟旁证日志独立保存原始增量，不能把“刷新跳了一截”直接判成虚增。原始计数下降时不按32位回绕补出流量。目标小时缺同期明细时保留待核实状态，不能凭总量擅自扣数。

## 4. 六个主按钮与更多设置

| 入口 | 执行与反馈 | 保护 |
| --- | --- | --- |
| 流量 | 开关蜂窝数据连接 | 本地管理与公网分开判断 |
| 性能 / 能效 | 性能开启大核；能效使用4小核，手动选择 | 切换显示“大核开启中 / 大核关闭中”；失败反馈，不启用自动休眠 |
| 4G / 自动5G | 点击立即发送目标，30秒倒计时只是等待提示 | 就绪提前结束；超时/无响应解除页面等待并重新查询 |
| OpenClash | 已安装时异步启停，状态来自后台 | 与 AdGuard 分别控制；检查核心、防火墙和DNS，而非只看进程 |
| 重启设备 | 重启整机 | 二次确认；不把模拟确认当实际重启验收 |
| 更多设置 | 展开同风格子区域 | 手机每行3个；展开状态与区域背景对应 |
| Wi-Fi | 开关热点 | 关闭二次确认，保留USB回退 |
| AdGuard Home | 已安装时异步启停 | 不重启OpenClash；DNS路由另行协调 |
| 信道 | 自动为选中样式，手动选择合法信道 | 按当前国家码和驱动过滤非DFS完整信道组 |
| 重启调制解调器 | 重启蜂窝模块 | 与重启整机分开，不混为同一操作 |
| 切换到Android | 调用配套系统切换路径 | 二次确认；Android回来需要原有切换入口 |
| 锁制式 / 频段 | 邻区、制式、锁定、保存并应用/保存/复位 | 固定版本接口，失败显示错误，不猜测AT返回 |

颜色：普通开关开启蓝色、关闭白色描边；性能红、能效绿；自动5G蓝、4G绿。切换中的按钮使用目标模式的过渡样式，不能以旧状态填充伪装成功。

## 5. CPU、内存和温度

CPU总占用、内存及温度不折叠。CPU详情点开后看各核心与频率；温度框下方的四个传感器左对齐。平均温度仅对有效读数计算，不能据此推断所有芯片实际结温。

2GB硬件内存包含设备树为调制解调器、安全和共享内存保留的区域；Linux可管理总量约1.4GiB属于当前设备布局。面板展示Linux实际可用总量，不伪造为2GB。

## 6. DNS与插件组合

常用链路为 `客户端 → dnsmasq:53 → AdGuard:5353 → OpenClash:7874`；插件关闭或不可用时按实际健康状态改走可用链路/直连。端口是本配套适配值，先核对自己的安装。

开关独立指进程启停不相互重启；DNS仍由独立协调器串行切换，公网断线不能被包装为解析成功。每次相关修改要验证双开、仅代理、仅过滤、双关四种组合，并恢复初始状态。OpenClash升级后需重新核对启动/守护是否覆盖DNS补丁。
