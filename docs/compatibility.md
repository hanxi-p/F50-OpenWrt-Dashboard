# 兼容与交付范围

## 适配基线

当前包基于 mu300-linux `v2026.10.11`、OpenWrt `25.12.5`、厂商 `5.4.254`，蜂窝接口 `sipa_eth0`，5GHz `radio0 / ap0`，MU300 / Aurora LuCI。来源版本见 [versions.json](../versions.json)。这不是最新系统版本声明，不能把某个组件升级当成整机升级。

面板安装器检查镜像版本、页面/接口、vnStat固定二进制哈希与SHA256；不匹配先适配。首次全量安装和恢复会重启rpcd，网页需重新登录。更新自己的环境前备份原件与状态。

## 文件交付与配置范围

| 范围 | 本仓库交付 | 还需要什么 |
| --- | --- | --- |
| 面板、RPC、采样、峰值、统计、分钟/错误日志 | `extras/dashboard` 整目录及 SHA256 | 匹配版本、vnstat2 / flock / curl与可用SSH |
| 六个快捷入口与插件状态 | 页面、异步worker、DNS协调 | OpenClash / AdGuard已自行安装；订阅/规则由本人提供 |
| 短信邮件 | `extras/sms-email` 独立包 | SMTP/TLS/msmtp、本人邮箱授权码，单独部署 |
| IPv6/SMS/回滚/USB等组件 | `extras/system-reliability` 独立包 | 先`install.sh --check`，不与页面安装混为一步 |
| SSH密钥、Wi-Fi/管理密码 | 操作入口链接到刷机指南 | 自己生成/设置，不分发维护者的密钥与密码 |
| MAC定向后台免密 | 不在通用面板安装器内 | 按设备单独配置、核对端口/关联/ACL；MAC可仿冒，不能视为强设备认证 |
| 12小时会话 | 当前设备的单独配置；通用面板安装器默认2小时 | 如需12小时，核对LuCI会话配置后单独设置与测试 |
| rpcd私有libubox修补 | 说明与上游来源；不自动分发定向二进制 | 原库/ABI/构建核对和隔离测试 |
| Android/boot/内核刷写 | 本仓库不执行 | 使用[原刷机指南](https://github.com/hanxi-p/F50-mu300-linux-guide)与上游工具 |

## 更新前后怎样检查

先读[风险清单](risk-register.md)、[修复历史](fix-history.md)与最近[回归记录](reviews/2026-10-15-repository-split.md)。明确改动范围后检查P0：SSH、热点、后台、DNS、锁/子进程和资源，再检查所改功能。

分别保存三层证据：语法/配置/实际部署；状态转换、锁顺序、并发、超时、异常清理和恢复；多轮正常、失败、边界与组合场景。可逆真实开关至少三轮往返，恢复初始状态；冷启动、真实弱信号、手机关联、长期运行或完整恢复未执行时明确未测。

本仓库保留此前失败和待核实项，包括厂商驱动问题与缺少同期原始计数的历史流量。部署过某个防护，不等于所有设备与所有条件都已验证。
