# 轻量身份判别器计划

目标是对“新观测—候选档案”配对进行同设备/不同设备判别，并允许拒判。设备类型分类是另一项任务，不能把同型号当同身份。

先使用正则化逻辑回归作为可解释基线，必要时与小型树模型比较。训练/校准在电脑完成，路由器只加载版本化系数和特征schema进行推断；不默认安装大型推理运行时，也不在路由器自动训练。

输入使用配对差异：同频段无线能力相似度、DHCP选项吻合、Client ID价值、服务名称/型号的匹配、特征重复性/共享程度、缺失掩码、关联时间关系和冲突。MAC/IP/UUID不作为可记忆的设备类别标签；源特征和归属标签分别保管。

正样本来自实际核实的同设备跨连接/跨MAC关系；负样本须包含真实的同型号、同系统、相似指纹设备。连续轮询不能当大量独立样本。训练与测试按设备和时间分组，避免同一连接快照跨集合泄漏。模型评价优先误合并、未知拒判和对规则基线的增益；未校准输出只称分数，不称正确概率。

模型先影子运行，版本校验失败或未知特征时回退规则。即使模型分数高，仍保留多候选/并发反证检查，不自动迁移免密或拉黑。当前没有训练好的真实身份模型或准确率验证结果。
